# Mobile Banking Application User Guide & FAQ

## 1. Registration & First-Time Login (အကောင့်သစ် ဖွင့်လှစ်ခြင်း နှင့် ပထမဆုံးအကြိမ် ဝင်ရောက်ခြင်း)

### Q: Mobile Banking အကောင့်အား မည်သို့ စတင်လျှောက်ထားရမည်နည်း။
Mobile Banking Application ကို စတင်အသုံးပြုရန် အောက်ပါအတိုင်း ဆောင်ရွက်နိုင်ပါသည်။
1. **Self-Registration (အက်ပ်မှ တိုက်ရိုက်လျှောက်ထားခြင်း):**
   * Mobile Banking App ကို App Store သို့မဟုတ် Google Play Store မှ ဒေါင်းလုဒ်လုပ်ပါ။
   * "Register New Account" ကို နှိပ်ပြီး မိမိ၏ **ဘဏ်အကောင့်နံပါတ်** နှင့် ဘဏ်တွင် စာရင်းသွင်းထားသော **ဖုန်းနံပါတ်** ကို ရိုက်ထည့်ပါ။
   * ဖုန်းသို့ ရောက်ရှိလာသော **OTP (One-Time Password)** ဂဏန်း (၆) လုံးကို ရိုက်ထည့်၍ အတည်ပြုပါ။
2. **Branch Registration (ဘဏ်ခွဲတွင် လျှောက်ထားခြင်း):**
   * အက်ပ်မှ လျှောက်ထားရာတွင် အဆင်မပြေပါက မှတ်ပုံတင် (NRC) မူရင်း ယူဆောင်၍ နီးစပ်ရာ ဘဏ်ခွဲတွင် သွားရောက် လျှောက်ထားနိုင်ပါသည်။

---

## 2. Password & Transaction PIN Management (စကားဝှက် နှင့် ငွေလွှဲ PIN နံပါတ် စီမံခန့်ခွဲခြင်း)

### Q: Password သို့မဟုတ် Transaction PIN မေ့သွားပါက မည်သို့ ဆောင်ရွက်ရမည်နည်း။
* **Login Password မေ့သွားပါက:**
  * Login ရေပြင်ရှိ "Forgot Password" ကို နှိပ်ပါ။
  * စာရင်းသွင်းထားသော ဖုန်းနံပါတ် သို့မဟုတ် NRC နံပါတ် ရိုက်ထည့်ပါ。
  * ဖုန်းသို့ ပို့ပေးသော OTP ဖြင့် အတည်ပြုပြီး Password အသစ် (ဂဏန်း၊ စာလုံး အကြီး/အသေး နှင့် သင်္ကေတ ပါဝင်သော အနည်းဆုံး ၈ လုံး) သတ်မှတ်ပါ။
* **Transaction PIN (၆ လုံးဂဏန်း) မေ့သွားပါက:**
  * အက်ပ်၏ "Settings" > "Security" > "Reset Transaction PIN" သို့ သွားပါ။
  * လုံခြုံရေး မေးခွန်းများ (Security Questions) ဖြေဆို၍ သို့မဟုတ် OTP အတည်ပြုချက်ဖြင့် PIN အသစ် ပြန်လည် သတ်မှတ်နိုင်ပါသည်။

## 3. Transfer Limits & Wallet Interoperability (ငွေလွှဲ ကန့်သတ်ချက် နှင့် Wallet သို့ ငွေလွှဲခြင်း)

### Q: Mobile Banking မှတစ်ဆင့် နေ့စဉ် ငွေမည်မျှ လွှဲပြောင်းနိုင်သနည်း။
* **Bank to Bank Transfer (ဘဏ်အကောင့်အချင်းချင်း လွှဲခြင်း):**
  * တစ်နေ့လျှင် အများဆုံး ကျပ် ၁၀,၀၀၀,၀၀၀ (သိန်း ၁၀၀ MMK) အထိ အခမဲ့ လွှဲပြောင်းနိုင်ပါသည်။
* **Wallet Top-Up / Transfer (KPay / WavePay သို့ လွှဲခြင်း):**
  * KPay သို့မဟုတ် အခြား Digital Wallet များသို့ တစ်နေ့လျှင် အများဆုံး ကျပ် ၅,၀၀၀,၀၀၀ (သိန်း ၅၀ MMK) အထိ လွှဲပြောင်းနိုင်ပါသည်。
  * Wallet လွှဲပြောင်းခ: တစ်ကြိမ်လျှင် ကျပ် ၂၀၀ သို့မဟုတ် ပမာဏ၏ 0.05% ကျသင့်မည် ဖြစ်ပါသည်[cite: 1, 2]。

## 4. Device Change & Unbinding (ဖုန်းအသစ် ပြောင်းလဲခြင်း နှင့် Device ချိတ်ဆက်မှု ဖြုတ်ခြင်း)

### Q: ဖုန်းအသစ် ပြောင်းသုံးပါက အကောင့်ကို မည်သို့ ပြောင်းရွှေ့ရမည်နည်း။
လုံခြုံရေးအရ Mobile Banking အကောင့်တစ်ခုသည် ဖုန်းတစ်လုံး (One Device Only) တွင်သာ သုံးစွဲနိုင်ပါသည်။
1. **ဖုန်းဟောင်းတွင် Unbind လုပ်ရန်:** ဖုန်းဟောင်းရှိ အက်ပ် > "Settings" > "Device Management" > "Unbind Device" ကို နှိပ်ပါ။
2. **ဖုန်းအသစ်တွင် Login ဝင်ရန်:** ဖုန်းအသစ်တွင် အက်ပ်ကို ဒေါင်းလုဒ်လုပ်၍ မိမိ၏ Username နှင့် Password ဖြင့် Login ဝင်ပြီး OTP အတည်ပြုချက် ရယူပါ။
3. **ဖုန်းဟောင်း ပျောက်ဆုံးသွားပါက:** ဖုန်းဟောင်း မရှိတော့ပါက Call Center ဖုန်း 09-123456789 သို့ ဖုန်းဆက်၍ မူရင်း Device အား Unbind လုပ်ပေးရန် တောင်းဆိုနိုင်ပါသည်[cite: 1, 2]。

## 5. Security Best Practices (လုံခြုံရေးဆိုင်ရာ သတိပြုရန် အချက်များ)

### Q: Mobile Banking အသုံးပြုရာတွင် မည်သည့် အချက်များကို သတိပြုရမည်နည်း။
* ဘဏ်ဝန်ထမ်းများ အပါအဝင် မည်သူ့ကိုမျှ မိမိ၏ **OTP Code**၊ **Password** သို့မဟုတ် **Transaction PIN** ကို မျှဝေခြင်း မပြုပါနှင့်[cite: 1, 2]。
* အများသုံး Public Wi-Fi များတွင် Mobile Banking အသုံးပြုခြင်းမှ ရှောင်ကြဉ်ပါ။
* သံသယဖြစ်ဖွယ် SMS သို့မဟုတ် Link များမှတစ်ဆင့် Login ဝင်ရောက်ခြင်း မပြုပါနှင့်။
